iPhone or iPad (Safari)

  1. Scan the game's code and open it in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen.
  4. Tap Add.

Android (Chrome)

  1. Scan the game's code and open it in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Install app (or Add to Home screen).
  4. Tap Install.

You need the internet the first time. After that, the games work offline.
